# 数据说明（初始数据 + 计量方式）

## atomic 计量（避免浮点误差）
- 本项目所有金额/数量/价格在接口与数据库层面都用整数表示：atomic
- 默认小数位：8
- 换算：`1` = `100000000` atomic

示例
- `0.001 BTC` = `100000` atomic
- `65000 USDT`（价格）= `65000 * 100000000` atomic（本项目把价格也按 8 位缩放存储）

前端为了简化展示，默认直接展示 atomic；如需小数展示，可用 `atomic / 1e8` 转换。
